01 · Before the list

What a skill is, and what goes in it

A skill is a folder with one instructions file, SKILL.md. Claude reads it whenever you ask for that kind of job, and follows the same steps every time. A saved prompt only works when you remember to paste it, and it drifts a little with every paste.

The skills do the repeat work. What goes into them is yours: what your customers said, what you can prove, how you talk. That's why the first skill on the list interviews you, and the second one collects your customers' words. Everything after that writes from those two.

What this means

None of these skills makes anything up. When a draft needs a number, a result or a review you didn't give, the skill asks you for it or leaves it out.

03 · The list

04 · Install

Get the files

In Claude Code, copy each skill's folder into ~/.claude/skills/ and start a new session. In the Claude app, turn on code execution in Settings, then upload each skill's folder as a zip under Customize › Skills. The step-by-step is in the README on GitHub.
